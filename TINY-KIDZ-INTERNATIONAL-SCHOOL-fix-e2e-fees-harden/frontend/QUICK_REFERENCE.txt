## 📝 Example Test

```javascript
test('should open fee structure dialog', async ({ page }) => {
  // Navigate to Fee Structure tab
  await page.click('[role="tab"]:has-text("Fee Structure")');
  
  // Click "Set Fee Structure" button
  await page.click('button:has-text("Set Fee Structure")');
  
  // Wait for dialog
  await expect(page.locator('[role="dialog"]')).toBeVisible({ timeout: 3000 });
  
  // Verify dialog title
  await expect(page.locator('text="Set Fee Structure"')).toBeVisible();
});
```

## 🚀 First Time Setup

```bash
# 1. Navigate to frontend
cd frontend

# 2. Install dependencies (if needed)
npm install

# 3. Install Playwright browsers (ONE TIME ONLY)
npx playwright install

# 4. Start servers in separate terminals:
# Terminal 1 - Frontend
npm run dev

# Terminal 2 - Backend
cd backend && node server.js

# Terminal 3 - Run tests
npm test
```

## 💡 Pro Tips

1. **UI Mode is best for debugging**: `npm run test:ui`
2. **Run specific tests**: `npx playwright test --grep "Fee Structure"`
3. **See failing test videos**: Reports auto-generated in `tests/playwright-report/`
4. **Use headed mode to watch**: `npm run test:headed`
5. **Debug one test**: `npx playwright test tests/fee-module-e2e.spec.js -g "specific test name"`

## ⚠️ If Tests Fail

| Error | Fix |
|-------|-----|
| Connection refused | Start backend: `node server.js` |
| Element not found | Use `npm run test:ui` to inspect |
| Timeout | Increase wait time in test |
| Login fails | Check admin account exists |
| API errors | Check backend logs |
